# Copy

## Identity
- Title: `😱 What did you do!?`.
- Favicon: the same emoji, as an inline SVG `data:` URI. No raster fallback ships, so a browser
  at the low end of the baseline that does not support SVG icons shows its own default icon.
- Subtitle: "Track daily wins".

## Hint
- Below the calendar sections: click a day to add +1, long-press or long-tap to reset to 0.

## Banner region
- A single region below the header carries the backup reminder, the import status line,
  and the storage error.

## Backup reminder
- Reminds the user to export a full backup once 24 or more hours have passed since the last export.
- With no export on record, it appears once at least one calendar exists.
- Evaluated on page load, not as a live countdown.
- Offers an export-now button and a dismiss button.
- Dismissing hides it for the session.

## Import status
- Import outcomes report on an inline status line in the banner region, never in a native dialog.
- A success status clears itself after about 5 seconds.
- A failure status persists until it is dismissed or superseded by a later status.

## Storage error
- When localStorage is unavailable or over quota, an error banner says so and the app keeps
  running in memory.

## Import review modal
- Names the situation: this is everything in the file, and each calendar is imported only if it
  is kept here.
- States that calendars already present here start out skipped, and that cancelling imports
  nothing at all.
- Column headers: **Calendar**, **Events**, **Last updated**. `Last updated` shows the calendar's
  own stored change timestamp, a wall-clock time unrelated to which dates it holds.
- Each row names the calendar, gives its event total, and shows its last-updated value.
- No presentation is specified for that value: the stored date is shown plainly, with no relative
  wording ("2 days ago") and no time of day. A format can be chosen later without changing the data.
- A calendar with no live counterpart carries a **Skip** checkbox, checked when the row is skipped;
  its row reads as "Skipped" beside the name.
- A calendar already present here carries a merge dropdown instead of the checkbox, labelled
  **When it already exists**. It is that row's only control, and its options are described by what
  they do to the calendar's days:
  - **Skip — keep the existing calendar** — nothing is imported for it and it is left as it is.
    Rows start here.
  - **Replace** — the imported calendar supersedes this one entirely, days included.
  - **Add together** — keep every date from both; a date in both adds its two counts.
    Name, color, and activity value stay as they are.
  - **Prefer imported** — keep every date from both; a date in both takes the imported count.
    Name, color, and activity value come from the import.
  - **Prefer existing** — keep every date from both; a date in both keeps the count already here.
    Name, color, and activity value stay as they are.
  The dropdown has no separate placeholder: the skip option is a real choice and is the default.
- With no calendars in the file, the list is replaced by a line saying the file holds no calendars,
  and only Cancel is offered.
- With every row skipped, a line below the list says nothing will be imported, and Apply stays
  available.
- The Skip checkbox appears only on a calendar with no live counterpart; a colliding row is skipped
  through its dropdown, so no row carries two ways to say the same thing.
- Actions are labelled Apply and Cancel.

## Unrecoverable data message
- Says the saved data could not be read, that nothing has been changed or overwritten, and that
  the app is running empty for this session.
- Asks the user to send the diagnostic to a developer, and says it describes only where the data
  failed — no calendar names, no day counts.
- Actions are labelled Copy diagnostic and Download diagnostic. There is no dismiss.
- A failed load also offers Download saved data and explains that this file contains the original calendars, for repair and re-import after keeping a copy and clearing the invalid saved state.
